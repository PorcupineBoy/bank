# 手机银行系统 - 部署文档

## 1. 架构概览

```
用户请求
    │
    ▼
nginx (cloud.porc.live:443)
    ├── /bank/                       → 前端 SPA（/var/www/bank/dist/）
    ├── /bank/api/                   → 后端 API（proxy_pass → 127.0.0.1:8080）
    ├── /b7e08a70e9b5/              → 其他服务:11414
    ├── /cloud/porcsite/             → 其他服务:10086
    └── /                            → 其他服务:2053
```

- **前端**：Vue 2 SPA，构建后为静态文件，由 nginx 直接托管
- **后端**：Spring Boot 2.7，Java 8，运行在 `8080` 端口
- **数据库**：MySQL 8.0（生产独立实例，非容器）
- **缓存**：Redis 7（生产独立实例，非容器）
- **部署路径前缀**：所有银行请求统一走 `/bank` 路径

## 4. 快速部署

### 4.1 拉取代码

```bash
git clone <仓库地址> /opt/bank
cd /opt/bank

# 切换到目标分支并拉取最新代码
git checkout feature_1.0.1
git pull
```

### 4.2 配置生产环境变量

```bash
cp deploy/.env.example deploy/.env
vim deploy/.env
```

填入真实的生产参数：

```ini
# 数据库
DB_HOST=192.168.1.100
DB_PORT=3306
DB_NAME=bank_db
DB_USER=bank_prod
DB_PASSWORD=生产数据库密码

# Redis
REDIS_HOST=192.168.1.100
REDIS_PORT=6379
REDIS_PASSWORD=生产Redis密码

# 密钥
JWT_SECRET=bank-mobile-jwt-secret-key-2026
AES_KEY=bank-mobile-aes-256-secret-key!!

# 后端端口
BACKEND_PORT=8080

# 域名
SERVER_NAME=cloud.porc.live
```

### 4.3 一键部署

```bash
chmod +x deploy/deploy.sh
sudo bash deploy/deploy.sh
```

脚本会自动检测并安装缺失的依赖（Java 11、Maven、Node.js 18），
支持 CentOS（dnf/yum）和 Ubuntu/Debian（apt）系系统。

脚本将依次执行：
1. 检查依赖（java / mvn / node / npm）
2. 构建前端 → `bank-frontend/dist/`
3. Maven 构建后端 → `bank-backend/target/*.jar`
4. 部署前端到 `/var/www/bank/dist/`
5. 生成 `application-prod.yml` 到 `/opt/bank-backend/`
6. 复制 JAR 到 `/opt/bank-backend/app.jar`
7. 安装 systemd 服务并启动
8. 复制 nginx 配置到 `/etc/nginx/conf.d/bank.conf`

### 4.4 手动部署 nginx 配置（推荐方式）

因为你的 `cloud.porc.live` 已有多个服务，建议手动将 `deploy/nginx/bank.conf` 中的 **location 片段** 插入到你的 `cloud.conf` 中。

```bash
# 查看 bank location 片段
cat deploy/nginx/bank.conf

# 编辑你的 cloud.conf
vim /etc/nginx/conf.d/cloud.conf
```

在 `server` 块中添加如下 location：

```nginx
# bank 路径路由
location = /bank {
    return 301 /bank/;
}

location ^~ /bank/ {
    alias /var/www/bank/dist/;
    index index.html;
    try_files $uri $uri/ /bank/index.html;

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?|ttf|eot)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
        access_log off;
        log_not_found off;
    }
}

location ^~ /bank/api/ {
    proxy_pass http://127.0.0.1:8080/api/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_connect_timeout 15s;
    proxy_read_timeout   30s;
    proxy_send_timeout   30s;
}
```

验证并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

## 5. 完整 cloud.conf 参考

你的 `cloud.porc.live` 完整配置（含银行路由）：

```nginx
server {
    listen 443 ssl http2;
    server_name cloud.porc.live;

    ssl_certificate       certs/cloud.porc.live.pem;
    ssl_certificate_key   certs/cloud.porc.live.key;
    ssl_stapling on;
    ssl_stapling_verify on;

    add_header Strict-Transport-Security "max-age=63072000; includeSubDomains; preload" always;
    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options DENY;

    # ===== 银行系统 =====
    location = /bank {
        return 301 /bank/;
    }

    location ^~ /bank/ {
        alias /var/www/bank/dist/;
        index index.html;
        try_files $uri $uri/ /bank/index.html;

        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?|ttf|eot)$ {
            expires 7d;
            add_header Cache-Control "public, immutable";
            access_log off;
            log_not_found off;
        }
    }

    location ^~ /bank/api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 15s;
        proxy_read_timeout   30s;
        proxy_send_timeout   30s;
    }

    # ===== 其他已有服务 =====
    location / {
        proxy_pass http://127.0.0.1:2053;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 900s;
    }

    location /b7e08a70e9b5/ {
        proxy_pass http://127.0.0.1:11414/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /cloud/porcsite/ {
        proxy_pass http://127.0.0.1:10086/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}

server {
    listen 80;
    server_name cloud.porc.live;
    return 301 https://$host$request_uri;
}
```

### 路径匹配优先级说明

nginx location 匹配规则：

| 优先级 | 写法 | 示例 | 说明 |
|--------|------|------|------|
| 1 | `= /path` | `= /bank` | 精确匹配，最高优先级 |
| 2 | `^~ /path/` | `^~ /bank/api/` | 前缀匹配，阻止正则检查 |
| 3 | `~* regex` | `~* \.js$ ` | 正则匹配（不区分大小写） |
| 4 | `/path/` | `/` | 普通前缀匹配，最长匹配胜出 |

其中 `/bank/api/`（长度 10）> `/bank/`（长度 6）> `/`（长度 1），所以 `/bank/api/` 请求会正确路由到后端。

## 7. 更新部署

代码更新后，重新部署：

```bash
cd /opt/bank
git pull
sudo bash deploy/deploy.sh
```

如果只更新后端（不改前端）：

```bash
cd /opt/bank/bank-backend
git pull
mvn clean package -DskipTests
sudo cp target/*.jar /opt/bank-backend/app.jar
sudo systemctl restart bank-backend
```

如果只更新前端：

```bash
cd /opt/bank/bank-frontend
git pull
npm install
VUE_APP_BASE_API=/bank/api npm run build
sudo cp -r dist/* /var/www/bank/dist/
```
