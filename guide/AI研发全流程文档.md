## 全流程流转图

```
基线文档                               评审意见                             修改执行
  集合                             33 项                                22 项
   │                                 │                                    │
   ▼                                 ▼                                    ▼
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  阶段 1   │───▶│  阶段 2   │───▶│  阶段 3   │───▶│  阶段 4   │───▶│  阶段 5   │
│  初稿     │    │ 多角色评审  │    │ 人工审核   │    │ 修改执行   │    │  定稿     │
│  (V0.1)  │    │  (V0.2)   │    │  (V0.3)   │    │ 22 项    │    │ (V1.0)   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
     │              │              │              │              │
     ▼              ▼              ▼              ▼              ▼
 8 份基线        4 角色         采纳 24 项     代码/文档/      终版基线
 自动生成        独立审查       部分采纳 4      测试同步        发布

───── 文档流转 ─────    ───── 评审流转 ─────    ───── 修改流转 ─────
```

**过渡规则**：
- 阶段 1 → 阶段 2：**文档就绪即触发** —— 初稿完成自动进入评审队列
- 阶段 2 → 阶段 3：**4 角色均完成后触发** —— 等待最慢角色（测试工程师）完成后汇总
- 阶段 3 → 阶段 4：**裁决完成即触发** —— 审批意见分派到各执行组
- 阶段 4 → 阶段 5：**所有采纳项完成即触发** —— 22 项全部完成后定稿
