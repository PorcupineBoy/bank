## 1.2 初稿核心内容

### 1.2.1 项目总体概览

| 项目 | 内容 |
|------|------|
| 项目名称 | 简易手机银行核心业务系统 |
| 项目定位 | 面向个人客户的智能移动金融服务平台 |
| 技术架构 | Spring Boot 2.7 + Vue 2.7 + Vant 2 + MySQL 8 + Redis 7 |
| 功能模块 | 账户登录、银行卡管理、交易转账、安全设置、AI智能助手（5大模块） |
| 接口总数 | 30个 REST API |
| 数据库表 | 7张业务表 |
| 部署方式 | Docker Compose（开发）+ Nginx + systemd（生产） |

### 1.2.2 功能模块清单（P0-P3）

| 模块 | 功能 | 优先级 |
|------|------|--------|
| F-AUTH | 用户注册、密码登录、短信登录、登出、会话管理 | P0 |
| F-CARD | 绑定/解绑银行卡、默认卡设置、余额查询、银行卡列表 | P0 |
| F-TRANS | 转账汇款、生活缴费、交易记录查询、收款方管理 | P0 |
| F-SEC | 交易密码管理、限额控制、风险提示二级确认、操作日志 | P0 |
| F-AI | 智能客服助手（MCP-Skill）、账单分析、异常交易预警 | P1-P3 |

### 1.2.3 技术架构决策记录

| 决策编号 | 决策内容 | 方案 | 理由 |
|---------|---------|------|------|
| AD-001 | 后端框架 | Spring Boot 2.7 + MyBatis-Plus | 生态成熟，金融场景验证充分 |
| AD-002 | 前端框架 | Vue 2.7 + Vant 2 | 移动端组件丰富，学习曲线平缓 |
| AD-003 | 认证方式 | JWT + Redis 单设备登录 | 无状态认证，支持滑动刷新 |
| AD-004 | 数据加密 | AES-256-CBC 加密身份证/卡号 | 满足监管合规要求 |
| AD-005 | AI架构 | MCP-Skill：LLM意图识别+Skill执行 | 松耦合，可扩展多家LLM提供商 |
| AD-006 | LLM提供商 | OpenAI/DeepSeek + 小米 MiMo | 多提供商降级，生产环境灵活切换 |
