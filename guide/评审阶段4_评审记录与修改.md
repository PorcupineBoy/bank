### MOD-012：新增 MCP 公开 REST 入口

**新增文件**：`McpController.java`

```java
@Slf4j
@RestController
@RequestMapping("/api/mcp")
public class McpController {

    @Autowired
    private McpSkillRegistry skillRegistry;

    @PostMapping("/execute")
    public Result<SkillResult> executeSkill(@RequestBody @Valid McpExecuteRequest request) {
        // 1. 查找 Skill
        McpSkill skill = skillRegistry.getSkill(request.getSkillName());
        if (skill == null) {
            throw new BusinessException(Constants.AI_SKILL_EXEC_ERROR, "Skill not found");
        }
        // 2. 执行 Skill
        SkillResult result = skill.execute(request.getParams());
        return Result.success(result);
    }

    @PostMapping("/skills")
    public Result<List<SkillMeta>> listSkills() {
        return Result.success(skillRegistry.getAllSkillMeta());
    }
}
```

**新增文件**：`McpExecuteRequest.java`（从 AiController 内部类提取为独立 DTO）

```java
@Data
@EqualsAndHashCode(callSuper = true)
public class McpExecuteRequest extends ReqBasic {
    @NotBlank(message = "Skill name is required")
    private String skillName;
    private Map<String, Object> params;
}
```

**文件**：`Transfer.vue`
